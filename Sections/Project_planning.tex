\subsection{Prosjektplanlegging}
\label{sec:prosjektplan}
\subsubsection{Arbeidsform og dokumentasjon}
Arbeidet gjennomføres i korte utviklingsrunder med sporbar sammenheng mellom krav, designvalg og tester. CAD-versjoner, bilder, produksjonsinnstillinger, testdata og beslutninger lagres fortløpende. Rapporten oppdateres etter hver hovedfase.

\subsubsection{Hovedfaser og milepæler}
Planen er foreløpig. Varighet og datoer tilpasses tilgang til verksted, komponenter og avtalt innleveringsfrist. Ambisjonen er rapportlevering i første halvdel av oktober 2026; dette er ikke en bekreftet frist.
\begin{enumerate}
    \item \textbf{Produktutvikling og konseptvalg.} Avklare oppgaverammer, utarbeide produktkrav og funksjonsanalyse, utvikle 3--5 konsepter og velge konsept med en begrunnet vurderingsmetode. Milepæl: kravspesifikasjon og valgt konsept dokumentert.
    \item \textbf{3D-design og produksjonsgrunnlag.} Modellere komponenter og sammenstilling, kontrollere dimensjoner, klaringer, toleranser og monterbarhet. Lage tegninger og deleliste. Milepæl: produksjonsklart underlag.
    \item \textbf{Produksjon og prototyping.} Produsere eller anskaffe deler, montere bilen og kontrollere akseloppretting, fri rotasjon og drivverk. Registrere avvik og nødvendige tilpasninger. Milepæl: fungerende prototype klar for systematiske tester.
    \item \textbf{Grunnleggende testing og forbedring.} Fastsette testprosedyre, gjennomføre en referanseserie og teste avgrensede designendringer. Milepæl: dokumentert funksjon, kjøredistanse, repeterbarhet og kravoppfyllelse.
    \item \textbf{Rapport og overføring til våren.} Ferdigstille resultater, diskusjon og konklusjon, samle CAD- og testgrunnlag og prioritere videre arbeid. Milepæl: fysisk prototype og ferdig rapport.
\end{enumerate}
Fasene kan overlappe, men produksjon bygger på kontrollert design og sammenlignende tester bygger på en fungerende referanseprototype. Det settes av tid til minst én korrigerende runde før sluttesting. Eventuelle formelle delleveranser avklares med veileder.

\subsubsection{Risikovurdering og tiltak}
\begin{itemize}
    \item Leveringstid og verkstedtilgang: avklar kritiske deler og bestill eller reserver tid tidlig.
    \item Skjeve aksler, friksjon og dårlig passform: kontroller kritiske mål og test delsystemer før full montering.
    \item Varierende opptrekk og underlag: standardiser testprosedyren og registrer avvik.
    \item Roterende deler og produksjonsarbeid: kontroller innfesting før opptrekk, hold hender og løse gjenstander unna og følg verkstedets sikkerhetsrutiner.
\end{itemize}
